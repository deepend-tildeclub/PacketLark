This is a preview for Windows and Linux. Back up your mailbox before updating.
Windows packages are unsigned. Linux needs a working desktop keyring.

Existing account files still work, and your first mailbox stays in place. Use
**Account → Add another account** to import another point or enter its details.
The account switcher keeps mail, drafts and discussions separate. **All unread**
links you to the right account. Check all accounts from the Account dialog or
tray, or pause automatic checks on an individual account.

**Account → Connection settings** can update the server and passwords. Queued
messages keep their original packet bytes; clear the Outbox before changing the
packet or AreaFix password. **Restore mailbox** saves a recovery copy and pauses
automatic checks so you can review restored outgoing mail before sending.

Please report problems at https://github.com/deepend-tildeclub/PacketLark/issues.
Include your OS, build version, and what you were doing. Leave out passwords,
account files, and mailbox backups.
